# 봇 명령어 사용법 (Commands)

이 문서는 텔레그램 봇을 통해 사용할 수 있는 명령어들과 그 상세 사용법을 안내합니다.

## 기본 명령어

### /start
- **설명**: 봇을 처음 시작하거나 상태를 확인할 때 사용합니다. 온보딩 메시지와 현재 활성 세션 상태를 표시합니다.
- **사용법**: `/start`

### /new [제목]
- **설명**: 새로운 AI 세션을 생성합니다. 제목은 선택 사항입니다.
- **사용법**: `/new [제목]`
- **예시**: `/new 로그인 버그 수정`

### /list
- **설명**: 현재 저장된 모든 세션 목록을 표시합니다. 페이지 네비게이션 버튼을 통해 목록을 탐색할 수 있습니다.
- **사용법**: `/list`

### /resume [번호]
- **설명**: 이전 세션을 다시 불러와 대화를 재개합니다. `/list` 명령어에서 확인한 세션 번호를 사용합니다.
- **사용법**: `/resume [번호]`
- **예시**: `/resume 3`

### /abort
- **설명**: 현재 진행 중인 AI 작업을 즉시 중단합니다.
- **사용법**: `/abort`

### /status
- **설명**: 봇의 현재 상태를 표시합니다. 활성 세션 정보, 현재 설정된 프로젝트 경로, 비용 정보 등을 확인할 수 있습니다.
- **사용법**: `/status`

### /agents
- **설명**: 사용 가능한 AI 에이전트 목록을 표시하고 변경할 수 있습니다. 인라인 키보드 버튼을 클릭하여 원하는 에이전트를 선택합니다.
- **사용법**: `/agents`

### /settings
- **설명**: 봇의 동작 설정을 변경합니다. 요약 모드, 요약 임계값, 출력 형식 등을 조정할 수 있습니다.
- **사용법**: `/settings`

### /history
- **설명**: 현재 활성 세션의 대화 내역을 `.md` 또는 `.html` 파일로 내보냅니다. `/settings`에서 내보내기 형식과 메시지 수를 설정할 수 있습니다.
- **사용법**: `/history`

## 큐 & 되돌리기 명령어

### /queue [메시지]
- **설명**: AI가 작업 중일 때 메시지를 큐에 추가합니다. AI가 현재 작업을 완료하면 자동으로 전송됩니다.
- **사용법**: `/queue [메시지]`
- **예시**: `/queue 유닛 테스트도 수정해줘`

### /clearqueue
- **설명**: 현재 채팅의 대기 중인 메시지 큐를 모두 비웁니다.
- **사용법**: `/clearqueue`

### /showqueue
- **설명**: 현재 큐 상태와 대기 중인 메시지를 확인합니다.
- **사용법**: `/showqueue`

### /undo
- **설명**: 마지막 AI 응답을 되돌립니다. AI가 파일에 적용한 변경사항이 취소됩니다.
- **사용법**: `/undo`
- **참고**: 가장 최근 응답만 되돌릴 수 있습니다. `/redo`로 복구할 수 있습니다.

### /redo
- **설명**: 되돌렸던 AI 응답을 다시 적용합니다.
- **사용법**: `/redo`
- **참고**: `/undo` 사용 후에만 사용 가능합니다.

### /help
- **설명**: 사용 가능한 전체 명령어 목록과 간단한 도움말을 표시합니다.
- **사용법**: `/help`

## 그룹 채팅 명령어

### /groupsettings
- **설명**: 그룹 채팅 전용 공유 설정을 관리합니다. 토론 라운드 수 설정과 현재 그룹에 있는 봇들의 상태를 확인할 수 있습니다.
- **사용법**: `/groupsettings`
- **참고**: 그룹 채팅에서만 사용 가능합니다. 개인 설정은 `/settings`를 사용하세요.
- **서브메뉴**:
  - **🎭 Debate 설정**: 토론 라운드 수 설정 (3, 6, 10, 무제한 또는 직접 입력)
  - **🤖 봇 상세**: 이 채팅방에 있는 봇들의 역할, 에이전트, 온라인 상태 확인

## 멀티봇 명령어 (🧪 테스트 중)

### /debate [라운드] [주제]
- **설명**: Writer와 Reader 봇이 주어진 주제에 대해 토론을 시작합니다.
- **사용법**: `/debate [주제]` 또는 `/debate [라운드] [주제]`
- **예시**: `/debate React vs Vue`, `/debate 10 TypeScript strict mode 적용 여부`
- **참고**: Writer/Reader 역할의 봇이 같은 그룹에 있어야 합니다.

### /review [대상]
- **설명**: Reader 봇에게 코드 리뷰를 요청합니다.
- **사용법**: `/review [검토 대상]`
- **예시**: `/review auth.ts의 보안 상태`

### /bots
- **설명**: 등록된 봇들의 현황(온라인/오프라인)을 확인합니다.
- **사용법**: `/bots`

### /addbot
- **설명**: 새 봇을 추가하는 마법사를 시작합니다. DM(개인 채팅)에서만 사용 가능합니다.
- **사용법**: `/addbot`

### /cancel
- **설명**: 진행 중인 마법사(예: /addbot)를 취소합니다.
- **사용법**: `/cancel`

## 유틸리티 명령어

### /git
- **설명**: 현재 프로젝트의 Git 상태를 한눈에 보여줍니다. 브랜치명, staged/unstaged/untracked 파일 수, 최근 커밋을 표시합니다. 인라인 키보드 버튼으로 diff 통계, 전체 diff, 확장 로그를 조회할 수 있습니다.
- **사용법**: `/git`
- **인라인 버튼**:
  - **📋 Diff**: staged/unstaged 변경 통계 표시
  - **📄 Full Diff**: 전체 diff 표시 (너무 길면 `.patch` 파일로 전송)
  - **📜 Log**: 최근 10개 커밋 표시
  - **🔄 Refresh**: Git 상태 새로고침

### /tunnel [포트|stop]
- **설명**: cloudflared를 이용해 로컬 서버를 외부에서 접근 가능하게 하는 터널을 생성합니다. 개발 서버 공유나 웹훅 테스트에 유용합니다. 자주 쓰는 포트 중 선택하거나 직접 입력할 수 있습니다.
- **사용법**: `/tunnel`, `/tunnel 3000`, `/tunnel stop`
- **인라인 버튼** (터널 비활성 시):
  - **3000 (React/Next)**, **5173 (Vite)**, **8080 (General)**, **4000 (GraphQL)**: 빠른 포트 선택
  - **Enter custom port...**: 임의의 포트 번호 입력
- **인라인 버튼** (터널 활성 시):
  - **Open**: 터널 URL 열기
  - **Stop**: 활성 터널 중지
- **참고**: 시스템에 `cloudflared`가 설치되어 있어야 합니다.

### /makeagent
- **설명**: AI가 맞춤형 시스템 프롬프트를 가진 커스텀 에이전트를 생성하는 마법사입니다. 원하는 에이전트를 설명하면 (예: "코드 리뷰어", "devops helper"), AI가 이름, 설명, 시스템 프롬프트가 포함된 완전한 에이전트 프로필을 생성합니다.
- **사용법**: `/makeagent`
- **진행 순서**:
  1. `/makeagent`를 보내 마법사를 시작합니다
  2. 만들고 싶은 에이전트를 설명합니다
  3. AI가 이름, 설명, 시스템 프롬프트가 포함된 초안을 생성합니다
  4. 검토 후 선택: ✅ 저장, 🔄 재생성, ✏️ 편집, 또는 ❌ 취소
  5. 저장 전에 에이전트 이름을 변경할 수 있습니다
- **참고**: 활성 프로젝트 세션이 필요합니다. 생성된 에이전트는 `/settings` → Custom Agent에서 확인할 수 있습니다.

## 일반 대화 (Prompting)

명령어가 아닌 일반 텍스트를 전송하면, 현재 활성 세션의 AI 에이전트에게 프롬프트(Prompt)로 전달됩니다. AI는 해당 요청에 따라 코드를 분석하거나 수정을 제안합니다.

## 설정 옵션 상세

`/settings` 메뉴를 통해 다음 항목들을 관리할 수 있습니다:

### 에이전트 & 모드 (`🤖 Agent & Mode`)
- **에이전트 선택**: 사용 가능한 AI 에이전트 간 전환합니다. 에이전트 이름을 클릭하면 활성화됩니다.
- **Review Mode**: 읽기 전용 모드를 토글합니다. ON일 때 파일 수정 요청이 자동으로 거부됩니다. Reader 봇은 기본 ON, Writer 봇은 기본 OFF입니다.

### 커스텀 에이전트 (`🎭 Custom Agent`)
- **커스텀 에이전트 선택**: `/makeagent`로 생성한 커스텀 에이전트 간 전환합니다. 에이전트 이름을 클릭하여 활성화하거나 제거합니다.

### 요약 (`📊 Summary`)
- **요약 모드 (Summary Mode)**: AI의 응답이 너무 길 경우, 경량 모델로 자동 요약하여 표시합니다.
- **요약 모델 (Summary Model)**: 요약 작업에 사용할 AI 모델을 선택합니다 (Claude CLI로 생성).
- **요약 임계값 (Summary Threshold)**: 이 길이를 초과하는 응답에 대해 요약 모드가 동작합니다. (기본값: 3,000자)
- **전문성 수준 (Expertise Level)**: 텍스트 요약과 음성 프롬프트 스타일을 조절합니다:
  - 🎮 **바이브 코더** — 전문 용어 없이 사용자 관점에서 설명합니다.
  - 👨‍💻 **개발자** — 파일명, 함수 시그니처, 테스트 결과 등 전체 기술 디테일을 포함합니다.
  - 🌱 **입문자** — 기술 용어에 간단한 설명을 덧붙여 배움을 돕습니다.

### 출력 (`📝 Output`)
- **출력 형식 (Output Format)**:
  - `formatted`: 마크다운(Markdown) 형식을 적용하여 보기 좋게 표시합니다.
  - `raw`: AI의 응답 원본을 그대로 표시합니다.

### 대화내역 내보내기 (`📜 History Export`)
- **대화내역 형식 (History Format)**: 내보내기 형식을 `.md`(Markdown) 또는 `.html`(HTML) 중 선택합니다.
- **대화내역 메시지 수 (History Limit)**: 내보낼 최근 메시지 수를 제한합니다. `0` 또는 `all`은 전체 내보내기입니다.

### 음성 (`🔊 Voice`)
- **음성 모드 (Voice Mode)**: 음성 응답을 활성화/비활성화합니다. ON일 때 AI 응답 후 🔊 듣기 버튼이 나타납니다.
- **자동 모드 (Auto Mode)**: ON일 때 AI 작업 완료 시 음성 MP3가 자동으로 생성되어 전송됩니다 — 버튼을 누를 필요 없습니다.
- **언어 (Language)**: 한국어 (🇰🇷) 또는 영어 (🇺🇸) TTS 출력을 선택합니다.
- **요약 길이 (Summary Length)**: 음성 요약 목표 길이: 500, 800, 1,200, 2,000자 중 선택합니다.
- **속도 (Speed)**: 재생 속도: 1.0x, 1.25x, 1.5x, 2.0x.
- **음성 성별 (Voice Gender)**: 여성 (👩) 또는 남성 (👨) 음성을 선택합니다.
- **전문성 수준 (Expertise Level)**: 요약과 동일 — 음성 프롬프트 스타일에 영향을 줍니다.
